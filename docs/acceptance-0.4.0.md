# 0.4.0 全局启用验收

2026-10-26，目标 DSH 0.2.1-rc.3；本次把工具和模型目录从专用 Preset 移到全局，
旧 Preset 身份保留。测试使用独立 Web 实例、专用工作区和 DeepSeek-V4.1-Flash / Max，
新场景均选择原生标准模式。日常桌面实例未改动。
11 份实际会话头的 `agentPreset` 均为 `standard`，每份都有 `render_intelligent_ui` 调用记录。

## 自动验证

- 534 项测试通过；13 项可选浏览器色彩测试未运行。
- 原生工具注册器验证多个 Preset 式作用域及子 Agent 继承同一工具和目录；显式禁止仍生效，
  插件卸载会移除所有继承者的工具及目录。
- `pnpm typecheck`、`pnpm build`、目录与 Bundle 快照检查通过。
- 0.3.0 旧 Preset 的已保存家庭开支界面在升级后恢复为 9,900 与 12,500 元，
  各自修改过的输入保持独立。

## 安装与边界

从插件页卸载 0.3.0，再输入原 GitHub 仓库地址安装，实际得到 0.4.0；启用后全局工具等 3 个组件运行正常。
安装锁定到 `d47fb5e71edc8695c18da8ab74d1d5316df6e449`，29 个 `dist` 文件及 Bundle 补丁的 SHA-256 与发布版本完全一致。
旧 Preset 采购会话的数量 4、单价 1,250、总额 5,900 在卸载重装后恢复。

随后直接新建标准模式会话生成出游预算，未切换专用 Preset；初始总额 2,600，住宿改为 1,500 后总额 2,900，
刷新后输入和结果恢复，显示已保存。此后的提交仅补充验收文档，不改变运行产物。

npm 注册及发布已按用户决定暂停；
npm 上同名包属于其他项目，本项目仍通过 GitHub 地址安装。

全局注册不取消 Preset 的显式工具限制。本版仅覆盖原生直接工具调用，PTC / run_code 嵌套调用尚未适配。
复杂复利、重复行保存等原有边界继续适用，见 [0.3.0 的说明](acceptance.md#适用边界)。
模型生成的说明和计算语义仍需核对，不将渲染成功或工具合同通过当成内容全部正确。
