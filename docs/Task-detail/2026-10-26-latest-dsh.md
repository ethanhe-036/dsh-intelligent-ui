# 新版 DSH 独立插件与开源发布

## 目标与范围

在官方 DSH 0.2.1-rc.3 上适配独立 Intelligent UI 插件，保留标准模式的有效能力，新增
intelligent-ui-preset；使用 DeepSeek 4.1 Flash / max 完成原九例及联网、文件场景，发布
独立可安装仓库，并验证“添加插件”入口。

不升级 HCT Runtime，不修改日常桌面配置、会话和数据，不包含 HCT 业务扩展，不处理 pi Fork。
源码从既有插件交付版本导出；本次仅调整独立包，不回写原宿主。

## 实施

- 适配 V4 紧凑 Assistant Stream、公开实时事件与冷启动 inspect；按真实调用身份匹配来源。
- 使用 SessionController.prompt 发送冻结输入，保留幂等回执与未知入队状态的恢复。
- Connection 认证精确路由承载 load/save/send；客户端采用当前共享 API RPC 格式。
- Conversation 节点放入 turn 层级，避免随工具工作区折叠隐藏。
- 复制固定上游标准 Preset；独立依赖、预构建 dist、目录和安装说明一同交付。

## 0.4.0：默认全局启用

用户要求安装并启用后直接在标准模式使用，无需选择专用 Preset；授权修改、测试、提交及推送 GitHub。
验收为原生标准模式下九例及联网、附件展示，继承/显式限制/卸载生命周期回归，以及仓库安装复验。
保留旧 Preset 身份供既有会话使用，工具与目录改在全局只注册一次。当前不扩展 PTC 嵌套调用，
不改日常桌面配置、输入持久化协议或渲染规则。npm 注册与发布按用户后续决定暂停，包名暂不变。
