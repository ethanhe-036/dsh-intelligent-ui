# DSH 0.2.1-rc.3 验收

2026-10-26，插件 0.3.0。在与 Windows 桌面版同版本的官方 DSH Web 中运行，
使用独立数据目录、Profile 和测试工作区。模型为 DeepSeek-V4.1-Flash，推理等级 Max。
没有改动日常桌面实例，也没有把 Web 实测写成桌面壳已实测。

- 标准模式的 22 个顶层插件条目连同嵌套配置、顺序与禁用状态完整保留；克隆增加 1 个 UI 工具条目。
- 531 项自动测试通过，13 项可选浏览器色彩测试未运行；类型检查与构建通过。
- 未认证访问 load/save/send 路由均返回 401。
- 发布包包含预构建代码和第三方许可，不需要运行构建脚本。

## 适用边界

普通生成式 UI、编辑、保存、刷新与明确发送按上述已验证范围使用。`$bindItem` 的重复行本地状态不自动持久化；
需要保存的表单使用具体 `$bindState` 路径或更新已绑定数组。每次直接工具调用创建独立界面，错误重生成保留原失败界面。

公式不支持任意 JavaScript、乘方或循环。复利等复杂计算应采用注明条件的预计算结果，或明确提交给模型重新计算，
不能宣称任意参数都在前端即时重算。模型生成的静态文字不会随着未发送的表单编辑更新。

本轮没有捕获到“流式工具尚未结束时手动停止并保留编辑”的完整浏览器证据；
中断/重试的来源及状态行为由自动测试覆盖，不据此宣称该浏览器场景已通过。
